# Avances P1L1

Esta carpeta reúne prototipos y avances utilizados durante el laboratorio de Semana 1.

- [`Avances_P1L1/`](Avances_P1L1/): benchmark LT1, verificaciones, informe y visor Unity experimental.
- [`losas_bidireccionales/`](losas_bidireccionales/): herramienta y ejemplos de distribución de cargas por áreas tributarias.

Estos avances son material de referencia de Semana 1 y no sustituyen las
fuentes organizadas de `P1L1/` ni el modelo independiente de `P1L2/`.
