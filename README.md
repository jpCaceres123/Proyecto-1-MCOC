# P1 - Caceres Juan Pablo

Repositorio de trabajo colaborativo para el proyecto de MCOC.

## Contenido

- `planos_edificio_ing/`: planos del edificio en formato DWG.
- `README/README.md`: contexto completo, objetivos y estado del proyecto.

Los archivos DWG se almacenan con [Git LFS](https://git-lfs.com/) para mantener el repositorio ligero.

## Flujo de trabajo

1. Crear una rama para cada tarea: `git switch -c nombre-de-la-tarea`.
2. Guardar cambios con un commit descriptivo.
3. Subir la rama y abrir un Pull Request para revisión.
4. Integrar los cambios a `main` después de revisarlos.

Para conocer el contexto actualizado del proyecto, consulta [`README/README.md`](README/README.md).
